# Gazellio 漏洞与补丁管理系统

## 使用方式

双击根目录中的 `index.html` 即可打开当前最新版系统。

该版本为纯前端演示系统，不依赖服务器、数据库或额外安装环境。页面内的扫描、补丁执行、任务处置、进度变化和中英文切换均使用本地模拟数据运行。

## 文件说明

- `index.html`：当前最新版，可直接打开使用。
- `.openai/hosting.json`：Sites 托管配置。
- `历史版本/`：v1 至 v5 的阶段性版本备份。

## 注意事项

- 建议使用最新版 Chrome、Edge 或 Safari 浏览器。
- 浏览器本地数据用于保存部分演示状态；如需恢复初始数据，可清除该页面的站点数据后重新打开。
- 当前版本不连接真实漏扫 Agent、CMDB、补丁仓库或自动化平台。
